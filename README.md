# Sammunat Landing Page

This project is a simple and responsive landing page built as part of the internship assignment for **Sammunat**.

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS

## Features
- Clean and minimal landing page design
- Component-based structure
- Fully responsive layout
- Deployed on a free hosting platform (Vercel)

## Getting Started

To run the project locally:

```bash
npm install
npm run dev
